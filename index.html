W-TinyLFU = Window LRU + TinyLFU 准入 + Count-Min Sketch 频率估计。新 key 先入小 Window； Window 溢出时其 LRU 作为 candidate，与主缓存 victim 比较 freq，胜者留下。
关于分区大小：Protected 有硬上限（main 的 80%）；Probationary 没有独立硬上限，它与 Protected 共享 main 空间， 实际可占到 mainSize - Protected 数量。只有 Protected 涨满后，Probationary 才回落到 ~20%（稳态占比）。 所以 Probationary 的分母会随 Protected 填充而动态收缩——这是正常的，不是溢出。
容量 ≤40 时显示逐项滑动动画；容量 >40（可到 1000）自动切换为聚合柱状视图（每行显示占用率 + 最近若干项）。 试试：切到「扫描」负载看新 key 被拒绝（扫描抵抗）；切到「Zipf/循环」看热点被命中并晋升； 单步逐帧观察草图计数增长与老化减半。
